0. **⚠ 本次审核暴露的方法论缺陷（最该留给后人的一条）**。`transcript` 的 `type=="user"` 条目序列**不等于**用户实际发过的消息全集：**用户在回答返回途中补发的消息（mid-turn 补充）不作为独立 user 条目落盘**。本次因此误判了 FD-02（把一条真实的用户更正判成"记录伪造"）与 FD-04 的一半，两条都由用户当场指出才发现。
   - **后果**：凡"用户从未说过 X"、"整轮无痕"这类判定，**只靠按行提取 user 条目是不可靠的**，会把记录比 transcript 更完整的地方反判成伪造。
   - **补救查法**：从 assistant 的 `thinking` 字段反查。本次 FD-02 的证据就在三条 thinking 里（L964、L976、L984），措辞一致地提到 "the user clarified they meant the annual pricing tier…, not a monthly figure"；FD-14 的用户纠正也在 L1490 的 thinking 里有独立痕迹。**下次做本类审核，须把 thinking 一并提取**，而非只取 text 块。
   - **仍存的盲区**：若某条 mid-turn 补充既未落 user 条目、assistant 的 thinking 又没提它，则从 transcript 侧无法证实也无法证否。这类情形下应**存疑而非判伪造**。
