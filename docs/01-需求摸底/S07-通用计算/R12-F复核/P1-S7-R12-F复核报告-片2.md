### TS-018：修复工序损耗计算（对应 FD-001）

#### 层1：方案设计（R8）

**设计要点**：
- 算法：`累计损耗 = previous_loss + 已提交卡自身损耗`
- 首道无前道累计，只记已提交卡自身损耗
- 未建卡、取消卡不贡献损耗
- `completed_qty` 保持原生汇总的已提交卡实际完工量
- 有正数量草稿卡时保留原生值，不从缺卡推算

#### 层2：代码实现（0c30dbc）

**落地位置**：`frappe_china/production/operation_flow.py:47` `sync_operation_loss`

**关键实现验证**：
```python
# 1. 初始化前道损耗
previous_loss = 0.0

# 2. 遇草稿卡保留原值
if not cards or any(card.docstatus == 0 and flt(card.for_quantity) for card in cards):
    previous_loss = flt(operation.process_loss_qty)
    continue

# 3. 累加：前道累计 + 本道已提交卡损耗
own = sum(flt(card.process_loss_qty) for card in cards if card.docstatus == 1)
loss = flt(previous_loss + own, operation.precision("process_loss_qty"))

# 4. 写入工序行
frappe.db.set_value("Work Order Operation", operation.name, 
    {"process_loss_qty": loss, "status": status}, update_modified=False)
previous_loss = loss
```

**与方案差异**：无。算法与 R8 §三 完全一致。

### TS-019：修复取消后回填超拆分数量（对应 FD-005）

#### 层1：方案设计（R8）

**设计要点**：
- 差额为正（加回）：逆序遍历未开工卡，每张加到拆分数量上限为止
- 差额为负（扣减）：保持原逻辑（从最后一张往前扣）

        max_add = split_qty - current if split_qty and split_qty > 0 else remaining

for card in reversed(ordered):
    decrease = min(flt(card.for_quantity), remaining)

### TS-020：修复按订单规则仓库粘连（对应 FD-008）

#### 层1：方案设计（R8）

**设计要点**：

- 逐组调用原生 `get_items_for_material_requests`，显式传 `for_warehouse`
- 无默认仓的行：加入 `problems`，不出建议
- 保留原生采购单位换算、勾选过滤、数量汇总与销售来源归集

#### 层2：代码实现（0c30dbc）

**落地位置**：`frappe_china/replenishment/rules.py:184` `order_proposals`

**关键实现验证**：
```python

for source in po_items:
    details = get_exploded_items({}, company, source["bom_no"], 0, 
                                 planned_qty=source["planned_qty"])
    for item_code, detail in details.items():
        warehouse = detail.get("default_warehouse")
        # 2. 缺仓处理
        if not warehouse:
            problems.append(f"物料 {item_code}（销售订单 {source['sales_order']}）：无默认仓库，不出建议")
            continue
        # 3. 构造原料行
        expanded.append({
            "item_code": item_code,
            "required_qty": flt(detail.get("qty")),  # 库存单位
            "include_exploded_items": 0,
            "sales_order": source["sales_order"],
            "default_warehouse": warehouse,
        })

# 4. 按仓库分组
by_warehouse = {}
for item in expanded:
    by_warehouse.setdefault(item["default_warehouse"], []).append(item)

# 5. 逐组调用原生函数
rows = []
for warehouse, group in by_warehouse.items():
    rows.extend(get_items_for_material_requests({
        "company": company,
        "po_items": group,
        "for_warehouse": warehouse,  # 显式传仓库
        "ignore_existing_ordered_qty": 1,
        ...
    }))
```
