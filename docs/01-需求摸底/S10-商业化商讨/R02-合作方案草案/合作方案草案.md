# 合作方案草案

> 草案，供双方商量，不是合同。
> 版本：v3，2026-11-14

## 一、写在前面

1. 这份草案把双方各自出什么、得什么都写出来，不藏条件。合作想长久，先要把账摆在桌面上。
2. 文中有三种标记：
   - **已商定**：双方谈话中已基本说定的做法
   - **待商量**：还要双方一起定，或只是一个起点
   - **待确认**：涉及法律、税务，须请律师、会计确认后才能落实
3. 价格全部是参考市场区间的估算，与合伙人商量时只作起点，拿到本地同行报价后再调整。
4. 文中称呼：
   - **合作公司**：双方合办的数字化合作公司，对外签约、收款
   - **技术方**：负责系统开发、实施、维护的一方，以其注册的技术公司持股合作公司、并为合作公司提供技术服务
   - **示范工厂**：第一家用上系统、并对外展示的工厂
   - **合伙人**：示范工厂的负责人，以及一起介绍客户的朋友
   - **介绍人**：某一单是谁介绍成交的，谁就是这一单的介绍人
5. 第二节写双方怎么合作，第三节写一起做哪些项目。各个项目可以逐个谈、逐个开始，不必一次谈定。

## 二、合作方式：合办数字化合作公司

### 1. 为什么一开始就合办公司

所有对外的合同都由合作公司签、钱都进合作公司，再由合作公司付介绍费、付技术服务费给技术方的公司。这样每一笔钱怎么来、怎么分，账上都看得清。

一句话概括分工：技术方出技术，示范工厂出场地和人脉，合伙人出销售；各自先按做的事拿钱，公司赚的钱再按股份分。

### 2. 各方出什么、得什么

| 谁 | 出什么 | 得什么 |
|---|---|---|
| 技术方 | 技术、实施交付、驻厂工程师课程、AI 调用与开发成本、全职投入的时间 | 技术服务费（主要收入）、35% 的分红、驻厂工程师培训班收入、技术归自己的公司、有一支不用自己找客户的销售队伍 |
| 示范工厂 | 场地、规范化配合、行业关系、销售、日常运营 | 以优惠价完成数字化改造；工厂转为示范基地，带来参观客户与培训业务；介绍费；分红；工人培训收入 |
| 其他合伙人 | 关系与销售 | 介绍费、年度业绩奖；核心几位另有股份与分红 |
| 合作公司 | 每单的 10% | 一整条产品线、示范基地这块招牌、学员与客户资源 |
| 外部工厂 | 改造费用 | 先参观再决定买；看得见的效率提升 |
| 驻厂工程师学员 | 学费 | 新技能，有机会成为实施工程师 |

### 3. 公司怎么组成

| 项 | 做法 | 状态 |
|---|---|---|
| 持股方式 | 技术方以自己的技术公司持股合作公司，两家公司之间签技术许可与服务合同 | 已商定，待确认 |
| 技术方股份 | 35% | 已商定 |
| 其他股东 | 核心几位合伙人直接持股，比例由合伙人之间商量；其他介绍人不持股，签渠道协议 | 已商定；比例待商量 |
| 表决与分红 | 同股同权、同股同分红 | 已商定 |
| 须技术方同意的事项 | 章程中写明涉及技术的若干事项须技术方同意（见下） | 已商定；事项清单待商量 |
| 出资 | 注册资本共 1～3 万元，各方按股权比例出少量现金；场地、人脉、技术都不作价入股 | 已商定，待确认 |
| 技术方投入 | 现在全职投入；培养出驻厂工程师后逐步交给他们 | 已商定 |

**须技术方同意的事项**（待商量，以下为起点）：更换技术供应商、技术对外许可、低于底价接单、竞争对手入股、对外担保。

持股 35% 超过三分之一，章程里的这些条款不会被单方面改掉。其他事项按股权比例表决，技术方不干预日常经营。

**出资为什么只出少量现金**：人脉、劳务依法不能作价出资；技术作价出资等于把技术转让给合作公司，与「技术留在技术方公司」相反。所以股权比例按各方的贡献谈，现金只是形式，够开户、刻章和头几个月记账即可。（待确认）

### 4. 以后有新股东进来

| 方式 | 怎么回事 | 对原股东的影响 |
|---|---|---|
| 增资 | 新股东把钱投进公司 | 所有人按比例被稀释 |
| 转让 | 某个老股东把自己的股份卖给新股东 | 钱归卖股份的人，其他人比例不变 |
| 原股东按比例追加 | 大家按原比例一起掏钱，比例不变；谁不掏，谁的比例下降 | 法律规定原股东有优先认缴权 |

**稀释举例**：公司投资前估值 300 万元，新股东投 100 万元，投资后估值 400 万元，新股东占 25%。原持股 35% 的股东降到 26.25%，但所持股份的价值 35% × 300 万 = 26.25% × 400 万 = 105 万元，一分没少。价格公道的稀释不吃亏，要防的是低价增资：协议写明增资价格不低于最近一次估值或净资产。

**技术方的原则**：增资时技术方的股份可以被稀释，但须技术方同意的事项不随股份稀释而减少。具体怎么写，到时再商量。（待确认：章程能否写成「修改这些条款须经技术方同意」，请律师看）

**每一笔收入**

| 收入 | 合作公司 | 技术方 | 介绍人 | 状态 |
|---|---|---|---|---|

### 7. 合作公司的 10% 怎么用

按以下顺序：

| 顺序 | 用途 | 说明 |
|---|---|---|
| 1 | 公司运转 | 代理记账、报税、银行账户、年报，每年几千元 |
| 2 | 风险准备金 | 用于退款、赔偿、售后纠纷；合作公司是签约方，出了问题先由它兜底；攒到 5 万元为止 |
| 3 | 共同获客 | 合作公司自己的宣传内容（AI 搜索推荐、视频号）、示范基地接待资料、行业展会 |
| 4 | 新项目所需硬件 | 在示范工厂试用新项目要买的传感器、平板等，归合作公司所有 |
| 5 | 年度业绩奖 | 见下 |
| 6 | 年底分红 | 剩下的按股份分 |

（已商定；业绩奖为新增，待商量）

**年度业绩奖**：分红只按股份，与每个人带来的业务量无关。为了多卖多得，每年从分红前利润里拿出一部分（比例待商量，起点 20～30%），按各人全年介绍成交的业务额发业绩奖。持股的、不持股的介绍人都能拿。（待商量）

**股东协议条款**（待商量，待确认）

| 类别 | 起点写法 |
|---|---|
| 出资 | 现金出资；场地以租赁方式提供，不折成股份；注册资本定小，5 年内缴足 |
| 表决与分红 | 同股同权、同股同分红；写明按实缴还是认缴 |
| 股份分期到手 | 4 年到手、满 1 年起；对所有股东都适用，包括技术方的公司 |
| 退出 | 未到手部分按象征价收回；已到手部分按净资产或约定公式回购；违反竞业或保密的，低价回购；继承人不直接成为股东，改为公司回购 |
| 转让 | 设锁定期；大股东卖股份时，其他股东可同条件一起卖；强制一起卖的门槛设高并设底价 |
| 增资 | 增资价不低于最近估值或净资产；新股东须签本协议 |
| 决策 | 须技术方同意的事项（见第 3 项） |
| 管理 | 只设一名董事；全体股东同意可不设监事；公章与 U 盾分管，大额两人签 |
| 财务 | 外包记账，每月报表发全体股东 |
| 分红 | 每年至少分配可分配利润的一定比例；先弥补亏损、再提 10% 法定公积金 |
| 竞业 | 逐项列出、写窄，双方都受约束；写明技术方公司的其他业务不受限 |
| 客户归属 | 合作期间客户归合作公司；退出后若干年内不得挖走 |
| 僵局 | 冷静期 → 第三方调解 → 一方报价、另一方选择买或卖 → 解散 |
| 争议 | 本地仲裁委：快、不公开 |

**技术许可与服务协议条款**（待商量，待确认）

| 条款 | 起点写法 |
|---|---|
| 许可范围 | 非独占、有期限，限地区与行业 |
| 知识产权 | 通用代码与改进归技术方的公司；各工厂配置与数据归该工厂 |
| 源代码 | 不交源代码；可交第三方托管，技术方公司停业或无法服务时，合作公司可取得源代码继续维护（这一条是给合作公司的保障） |
| 赔偿上限 | 以合同金额为限 |
| 控制权变化 | 合作公司换控股股东时，许可重新谈 |
| 终止 | 提前通知；终止后协助交接若干个月 |
| 双向排他 | 合作公司的数字化项目优先或独家交给技术方的公司；技术方的公司不在本地区另找驻厂工程师线下培训的合作方 |

**AI 能帮上哪些忙**

分工的原则：规则写得清的交给 ERP，要看材料下判断的交给 AI，拍板的交给人。AI 打八成草稿，人做两成判断。

办公室：

| 岗位 | 以前 | 用 AI 以后 |
|---|---|---|
| 销售报价 | 客户微信发来图纸或截图，人工看规格、查价格、做报价单，半小时以上 | AI 读图，提出线径、外径、圈数、材质，生成报价草稿，人核一遍就发 |
| 销售跟进 | 靠记性 | 微信语音转成订单要点，到期自动提醒跟进 |
| 采购 | 几家供应商的报价单手工汇总比较 | 把报价单丢进去，自动出比价表 |
| 财务 | 发票、流水手工录入；月底跟客户对账逐行核对 | 识别后自动录入；两份对账单自动标出差异；自动起草催款函 |
| 人事行政 | 考勤异常逐条翻；写招聘启事 | 自动汇总异常；生成招聘启事和面试题 |
| 管理 | 开会记笔记，事后整理 | 录音后自动出纪要和待办；周报从系统数据自动生成 |
| 外贸 | 邮件翻译、写回复 | 自动翻译并起草回复 |
| 老板 | 想知道数字要打电话问人 | 直接问「这个月哪个客户回款最慢」 |

**财务 AI 工作流**

| 工作流 | 流程 | AI 下的判断 |
|---|---|---|
| 经营月报 | ERP 出数 → 与上月、预算比 → 挑变化最大的几项 → 到凭证里找原因 → 写成老板看得懂的月报 → 财务审核 | 哪些变化值得说、原因是什么（如制造费用涨 18%，是因为 3 张维修单） |
| 应收催收 | 每天看账龄、回款历史、聊天记录 → 欠款客户分类 → 按类型起草催款话术 → 建议是否停供 → 人发出 | 客户是忘了、资金紧张，还是对货有意见 |
| 客户对账 | 客户发来的 Excel、PDF、照片 → AI 读出后与 ERP 逐行核 → 解释差在哪 → 起草回复 | 读懂各种格式；差额是没开票、在途还是价格不同 |
| 报销审核 | 读发票、报销单、出差审批 → 对照文字报销制度 → 标出异常并说明 → 人审批 | 拿一段文字规定判断一张票是否合规 |
| 毛利漏在哪 | 实际毛利与标准毛利对不上 → 查哪些工单、哪些材料涨价 → 写分析 | 找出主因 |
| 资金预测 | 结合各客户平均晚付天数、应付到期、工资 → 未来 13 周资金预测与说明 | 估每个客户实际哪天付款 |
| 财税政策解读 | 读新的财税公告 → 说明对本公司的影响并附出处 → 人核实 | 哪些条款与本公司有关 |

**销售 AI 获客工作流**

| 步骤 | AI 做什么 | 人做什么 |
|---|---|---|
| 1 画理想客户 | 从 ERP 现有客户里找毛利最高、回款最好的那类（行业、地区、订单规模） | 确认 |
| 2 找线索 | 从企业公开信息、1688、展会名录、招标公告、招聘信息（在招人说明在扩产）里找符合画像的企业，并写理由 | — |
| 3 研究打分 | 读对方官网的产品，推测会用什么弹簧，按匹配度打分 | 挑要跟的 |
| 4 首次联系 | 结合对方产品起草针对性的第一条消息 | 审核后一条条发，不群发 |
| 5 内容吸引 | 把工厂素材写成视频号、抖音脚本与公众号文章 | 拍摄 |
| 6 回复询价 | 微信、1688、官网来的询价，AI 读图提规格、追问缺的参数、按 ERP 报价规则给区间，转给销售 | 定价、谈判 |
| 7 跟进 | 沟通记进 CRM，提醒下一步，按客户上一条消息起草跟进；发现下单变少时提醒 | 维护关系 |
| 8 复盘 | 每周分析赢单、丢单的原因 | 改话术与画像 |

合规：只用企业公开信息，不买个人手机号数据，不群发骚扰。最好的演示是合作公司自己先用这套流程找客户。

**在 AI 搜索中被推荐**

目标是让豆包、元宝、DeepSeek 等 AI 在回答「哪家弹簧厂做得好」一类问题时，提到并推荐合作公司或客户工厂。

| 步骤 | 做什么 | 交付物 |
|---|---|---|
| 1 诊断 | 整理 30～50 个买家真会问的问题，逐个去问 AI，记下有没有提到、排第几、引用了哪个来源、正面还是负面 | 基线报告 |
| 2 定内容 | 根据 AI 爱引用的来源，规划要写什么：参数、对比、案例、常见问题 | 内容清单 |
| 3 做内容 | 写成结构清楚、有具体数据、可以被直接引用的内容：官网常见问题页、百科词条、头条文章、带字幕和文案的抖音视频 | 内容本身 |
| 4 分发 | 发到 AI 常引用的平台；一次拍摄多处分发（视频号、抖音、公众号、头条、官网） | 发布记录 |
| 5 监测 | 每月复测同一批问题，看提及率、排名、正负面怎么变 | 月报 |

先给合作公司自己做，做出效果再作为服务卖给其他工厂。各平台的引用来源以实测为准。

**调机仿真软件**

先做网页版 3D 参数仿真：学员在虚拟面板上输入参数，3D 画面看弹簧成型，量自由长度、外径、节距判断合不合格，并预设常见故障练排查。重点练调机（送线长度、芯轴与顶杆位置、节距、切断时机），因为调机费钢丝、占机器、靠老师傅带。网页打开就能用，不绑某个品牌的机器。

开工前要准备：示范工厂卷簧机的品牌与控制器型号、一段老师傅从头到尾调机的录像、钢丝回弹的实测数据（用来修正仿真结果）。

**15% 怎么落实**（待商量，待确认）

| 要写清的 | 起点写法 |
|---|---|
| 「全部数字化基建」包括什么 | 列清单：仿真软件、线上学习平台、SOP 视频、题库、培训档案，加头若干年维护；清单以外的新需求另收费 |

| 股份什么时候到手 | 与交付挂钩，如学习平台上线 5%、仿真软件上线 5%、第二年运行正常 5% |

**培训资质**：发国家认可的职业技能等级证书、拿政府培训补贴，一般要有人社部门的资质；不发证的企业内训，营业范围含培训即可开展。工人培训的收入很大程度取决于补贴，须先向当地人社局问清楚。
