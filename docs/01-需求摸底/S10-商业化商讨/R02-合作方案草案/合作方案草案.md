# 合作方案草案

> 草案，供双方商量，不是合同。
> 日期：2026-11-13

## 一、写在前面

1. 这份草案把双方各自出什么、得什么都写出来，不藏条件。合作想长久，先要把账摆在桌面上。
2. 文中有三种标记：
   - **已商定**：双方谈话中已基本说定的做法
   - **待商量**：还要双方一起定，或只是一个起点
   - **待确认**：涉及法律、税务，须请律师、会计确认后才能落实
3. 价格全部是参考市场区间的估算，与合伙人商量时只作起点，拿到本地同行报价后再调整。
4. 文中称呼：
   - **技术方**：负责系统开发、实施、维护的一方，以其注册的公司签约
   - **示范工厂**：第一家用上系统、并对外展示的工厂
   - **合伙人**：示范工厂的负责人，以及一起介绍客户的朋友

## 二、合作怎么一步步走

合作分级推进。每一级都可以停住，上一级跑顺了再往下一级，不必一次谈到底。

**数字化这条线**

| 级 | 做什么 | 双方各得什么 | 什么时候走到这一级 |
|---|---|---|---|
| 0 | 技术方注册公司 | 能签合同、开发票 | 现在 |
| 1 | 示范工厂买 ERP | 示范工厂用上 ERP，并成为示范基地 | 现在 |
| 2 | 合伙人介绍其他工厂 | 介绍人每单拿 30% 介绍费 | ERP 上线稳定，示范工厂愿意带人参观 |
| 3 | 新项目在示范工厂试用 | 示范工厂半价用上新项目，用以后的分成付款 | 技术方在示范工厂发现值得做的点，并与合伙人谈过可行性 |
| 4 | 合办 FDE 培训班 | 线下课收入双方五五分 | 课程备好、有第一批学员 |
| 5 | 合办数字化合作公司 | 共同对外签约，共同分红 | 外部订单有三五单，需要一个统一的签约主体 |

第 2～4 级不分先后。现在位于第 0～1 级之间。

工人培训如果也一起合作，路线见第八节。

## 三、ERP 收费

| 项 | 做法 | 状态 |
|---|---|---|
| 模块费 | 13 万元，含已做好的 9 个模块（见下表） | 待商量（估） |
| 实施费 | 按人天收，每天 1500 元；一家工厂约 30～60 天，合计 4.5～9 万元 | 待商量（估） |
| 外部工厂首期 | 模块费加实施费，合计 17.5～22 万元 | 待商量（估） |
| 合伙人自家工厂 | 模块费打七折（9.1 万元），免实施费 | 已商定 |
| 年维护费 | 模块费的 10～15%，每年 1.3～2 万元；合伙人自家工厂同样按 13 万元计，不打折 | 已商定（比例待商量） |
| 介绍费 | 介绍成交的，按整单（模块费加实施费）的 30% 付；年维护费不分 | 已商定 |
| 介绍费怎么分 | 技术方每单固定拿 70%；另外 30% 怎么分由合伙人之间商量，付给合伙人书面指定的收款人 | 已商定 |
| 合同范围 | 合同写清做哪些事；超出范围的另开变更单，按人天收费，介绍人同样拿 30% | 已商定 |
| 谁定价 | 市场价由合伙人定；包括底价在内的所有价格双方共同商量 | 已商定 |
| 起步收什么 | 起步阶段只收 ERP 的钱，签约即付款；其他项目按第四节办 | 已商定 |

**9 个模块**

| 模块 | 万元 |
|---|---|
| 财务 | 1 |
| 进销存 | 2 |
| 生产制造 | 3 |
| 车间管理 | 2 |
| 销售漏斗 | 1 |
| 手机端 | 0.5 |
| 质检与控制图 | 2 |
| 计件工资 | 0.5 |

## 四、ERP 以外的新项目

| 项 | 做法 | 状态 |
|---|---|---|
| 流程 | 双方一起探讨可行性 → 技术方开发 → 在示范工厂试用到运行稳定 → 双方共同决定是否推向市场 → 按合伙人定的市场价销售 | 已商定 |
| 谁判断可行 | 技术方判断技术上做不做得出来；合伙人结合成本判断市场上卖不卖得动 | 已商定 |
| 运行稳定的标准 | 示范工厂连续用 4～8 周、员工每天在用、没有丢数据一类的问题；双方签一页纸确认 | 已商定 |
| 研发成本 | 由技术方承担，不向合伙人收取 | 已商定 |
| 试验厂价格 | 按市场价的一半计。一开始不用付，项目推向市场后，用该试验厂合伙人卖这个项目拿到的 30% 介绍费来付，付清后照常拿 30%。金额按推向市场那天的市场价锁定，不设期限。项目最终没有推向市场的，不用付 | 已商定 |
| 其他合伙人自家工厂 | 按市场价打九折 | 已商定 |
| 介绍给外部工厂 | 按市场价，介绍人拿 30% | 已商定 |
| 合伙人中途退出 | 半价优惠取消。退出后还想继续用，须把价格补到全价：全价减去已经用介绍费付掉的部分，剩下的补齐 | 已商定 |

**退出时补多少（例：项目全价 10 万元，试验厂按 5 万元计）**

| 退出时已用介绍费付了 | 想继续用，还要补 | 合计 |
|---|---|---|
| 0 | 10 万元 | 10 万元 |
| 2 万元 | 8 万元 | 10 万元 |
| 5 万元（半价已付清） | 5 万元 | 10 万元 |

## 五、FDE 培训班

FDE 指驻厂工程师：懂工厂业务、也能动手配置系统的实施人员。

| 项 | 做法 | 状态 |
|---|---|---|
| 目的 | 除收学费外，也为其他工厂和技术方培养 FDE，解决交付只靠一个人的问题 | 已商定 |
| 谁来合作 | 技术方的公司与示范工厂直接合作，不经过合作公司 | 已商定 |
| 线上课 | 收入归技术方，开课不受限制 | 已商定 |
| 线下实践课 | 只在示范工厂上，未经示范工厂同意，不与别的工厂合办；先扣除材料、学员意外险等直接成本，再双方五五分 | 已商定 |
| 怎么算线下 | 含工厂实操的整门课都算线下 | 已商定 |
| 学员 | 去向自由；线下学员都买意外险、签安全须知；其他工厂招走学员时收推荐费，归合作公司 | 已商定 |

## 六、示范基地与服务内容

**业务路径**：参观示范基地 → 诊断 → 改造 → 运营 → 培训。获客主要靠请其他工厂来示范基地参观。

**ERP 以外可提供的服务**（每项按第四节的新项目办法推进）：

- 培训配套，包括调机仿真软件
- 示范基地展示
- 规范化文档
- 宣传获客，包括在 AI 搜索中被推荐、视频号
- AI 助手与知识库
- IT 运维

**仿真软件**：先做网页版 3D 参数仿真，重点练调机。

## 七、数字化合作公司（第 5 级）

| 项 | 做法 | 状态 |
|---|---|---|
| 什么时候成立 | 走到第 5 级再成立，此前合同由技术方的公司签 | 已商定 |
| 持股方式 | 技术方以自己的公司持股合作公司，两家公司之间签技术许可与服务合同 | 已商定，待确认 |
| 技术归属 | 软件与技术归技术方的公司，AI 调用费用由技术方承担；各工厂的配置与数据归该工厂 | 已商定 |
| 技术方投入 | 现在全职投入；培养出 FDE 后逐步交给他们 | 已商定 |
| 成立后的 ERP 合同 | 由合作公司签。每单扣介绍费后付技术服务费给技术方的公司，合作公司自留 10～15% | 做法已商定；比例待商量，待会计确认 |
| 自留部分怎么用 | 依次用于：公司运转 → 风险准备金（攒到 5 万元为止）→ 共同获客 → 新项目所需硬件 → 年底分红 | 已商定 |
| 合伙人怎么进来 | 核心几位直接持股；其他人签渠道协议，业绩达标后从预留股份中分 | 已商定 |
| 技术方需要的 | 不要求控股；持股 34% 以上，并在章程中写明涉及技术的若干事项须技术方同意 | 已商定；事项清单待商量 |
| 表决与分红 | 同股同权、同股同分红 | 已商定 |
| 出资 | 注册资本共 1～3 万元，各方按股权比例出少量现金 | 已商定，待确认 |
| 法定代表人与账户 | 示范工厂负责人任法定代表人，公章由其保管；技术方可以查账、收到账通知，大额付款由技术方复核（两级 U 盾）；技术服务费在客户回款后若干天内付给技术方 | 已商定；天数与大额标准开户时定 |

**须技术方同意的事项**（待商量，以下为起点）：更换技术供应商、技术对外许可、低于底价接单、竞争对手入股、对外担保。

持股 34% 以上，是为了让章程里的这些条款不会被单方面改掉。其他事项按股权比例表决，技术方不干预日常经营。

**要签的文件**（由律师起草）：

| 什么时候 | 文件 |
|---|---|
| 现在 | 合作备忘录；每位介绍人一份渠道协议；保密协议 |
| 每个新项目 | 一页立项附件 |
| 办 FDE 班时 | 培训合作协议 |
| 成立合作公司时 | 股东协议、公司章程、技术许可与服务协议 |

## 八、工人培训（若也一起合作）

| 项 | 做法 | 状态 |
|---|---|---|
| 公司 | 与数字化合作公司分开，另办一家培训公司 | 已商定 |
| 合作路线 | 三级：0 示范工厂自己办培训 → 1 技术方做培训配套（视频教程、仿真软件、线上学习平台、题库），按新项目办法、试验厂半价 → 2 合办培训公司 | 已商定 |
| 技术方的股份 | 以全部数字化基建换培训公司 15% 的股份 | 待商量 |
| 15% 怎么落实 | 基建列清单、写明维护年限；按比例出少量现金，不把基建作价入股；股份随交付分阶段到手；通用软件归技术方的公司、免费授权使用，该厂专属内容归培训公司 | 待商量，待确认 |
| 课程教材 | 工人培训课程教材归培训公司；FDE 课程归技术方 | 待商量 |

## 九、还要商量和确认的事

| 事项 | 什么时候定 |
|---|---|
| ERP 最终价格 | 拿到本地同行报价后，双方商量 |
| 年维护费比例（10% 还是 15%） | 签 ERP 合同前 |
| 合作公司自留比例与税负 | 算完交付成本、会计核过后 |
| 回款后几天付技术服务费、大额付款标准 | 开合作公司账户时 |
| 须技术方同意的事项清单 | 谈股东协议时 |
| 培训公司 15% 股份的写法 | 谈培训公司股东协议前 |
| 培训资质与补贴 | 示范工厂向当地人社局问过后 |
| 所有合同与公司设立 | 律师起草、会计核税 |
