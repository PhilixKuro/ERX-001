# 合作方案草案

> 草案，供双方商量，不是合同。
> 版本：v9，2026-11-14

## 一、写在前面

1. 这份草案是技术方先按自己的想法拟的，把双方各自出什么、得什么都写出来，不藏条件。全部内容都可以商量。
2. 价格是参考市场区间的估算，拿到本地同行报价后再调整。
3. 涉及法律、税务的写法，最终以律师、会计的意见为准。
4. 文中称呼：
   - **数字化合作公司**：合伙人合办的公司，数字化业务对外签约、收款
   - **工人培训合作公司**：如果工人培训也一起合作，另办的一家公司，与数字化合作公司分开
   - **技术方**：负责系统开发、实施、维护的一方，以其注册的技术公司持股数字化合作公司、并为它提供技术服务
   - **合伙人**：一起合办数字化合作公司的股东。目前除技术方外，合伙人都负责销售
   - **示范工厂**：用上系统、对外展示并接待参观的工厂。示范工厂与合伙人是两回事，不是每位合伙人都要做示范工厂
   - **介绍人**：某一单是谁介绍成交的，谁就是这一单的介绍人；可以是合伙人，也可以是签了渠道协议的其他人
5. 第二节写怎么合作，第三节写一起做哪些项目。各个项目可以逐个谈、逐个开始，不必一次谈定。

## 二、合作方式：合办数字化合作公司

### 1. 为什么一开始就合办公司

所有数字化业务的合同都由数字化合作公司签、钱都进数字化合作公司，再由它付介绍费、付技术服务费给技术方的公司。这样每一笔钱怎么来、怎么分，账上都看得清。

一句话概括分工：技术方出技术，销售合伙人出客户，示范工厂出场地；各自先按做的事拿钱，公司赚的钱再按股份分。

### 2. 各方出什么、得什么

| 谁 | 出什么 | 得什么 |
|---|---|---|
| 技术方 | 技术、实施交付、服务器与维护、驻厂工程师课程、AI 调用与开发成本、全职投入的时间 | 技术服务费（主要收入）、35% 的分红、驻厂工程师培训班收入、技术归自己的公司、一支不用自己找客户的销售队伍 |
| 销售合伙人 | 行业关系与销售、参与定价 | 介绍费、年度业绩奖、按股份分红；自家工厂上系统有优惠 |
| 示范工厂 | 场地、规范化配合、接待参观、新项目试用与反馈 | 以优惠价完成数字化改造；参观带来的客户与名气；驻厂工程师线下课分成；新项目试验厂半价 |
| 数字化合作公司 | 作为共同对外签约的主体；钱先进公司、再分给技术方和介绍人，对双方都是一层保障；承担公司官网、AI 搜索推荐等宣传费用和日常运营成本；发年度业绩奖与分红 | 每单的 10% |
| 外部工厂 | 改造费用 | 先参观再决定买；看得见的效率提升 |
| 驻厂工程师学员 | 学费 | 新技能，有机会成为实施工程师 |

### 3. 公司怎么组成

| 项 | 做法 |
|---|---|
| 持股方式 | 技术方以自己的技术公司持股数字化合作公司，两家公司之间签技术许可与服务合同 |
| 技术方股份 | 35% |
| 其他股东 | 核心几位销售合伙人直接持股，比例由合伙人之间商量；其他介绍人不持股，签渠道协议 |
| 表决与分红 | 同股同权、同股同分红 |
| 须技术方同意的事项 | 章程中写明涉及技术的若干事项须技术方同意（见下） |
| 出资 | 注册资本共 1～3 万元，各方按股权比例出少量现金；场地、人脉、技术都不作价入股 |
| 技术方投入 | 现在全职投入；培养出驻厂工程师后逐步交给他们 |

**须技术方同意的事项**（起点）

| 事项 | 指什么 | 为什么要技术方同意 |
|---|---|---|
| 更换技术供应商 | 数字化合作公司把系统的开发、实施或维护交给技术方以外的公司或个人；或另找人做同类系统卖给客户 | 技术方以技术入伙、全职投入，换掉技术方等于拿走它的贡献 |
| 技术对外许可 | 把技术方许可给数字化合作公司使用的软件，再许可、转卖或交给第三方，包括源代码、安装包、系统账号 | 软件归技术方的公司，数字化合作公司只有使用权 |
| 低于底价接单 | 报价低于双方共同定的底价，或免费赠送模块、人天 | 每一单都由技术方交付，低于底价会让交付亏本 |
| 竞争对手入股 | 新股东或股份受让人是做同类数字化系统或服务的公司、个人，或与它们有关联 | 防止技术和客户资料流到对手手里 |
| 对外担保 | 数字化合作公司为任何公司或个人的债务作担保 | 担保出了事由公司赔，最终由全体股东承担 |

持股 35% 超过三分之一，章程里的这些条款不会被单方面改掉。其他事项按股权比例表决，技术方不干预日常经营。

**出资为什么只出少量现金**：人脉、劳务依法不能作价出资；技术作价出资等于把技术转让给数字化合作公司，与「技术留在技术方公司」相反。所以股权比例按各方的贡献谈，现金只是形式，够开户、刻章和头几个月记账即可。

### 4. 以后有新股东进来

| 方式 | 怎么回事 | 对原股东的影响 |
|---|---|---|
| 增资 | 新股东把钱投进公司 | 所有人按比例被稀释 |
| 转让 | 某个老股东把自己的股份卖给新股东 | 钱归卖股份的人，其他人比例不变 |
| 原股东按比例追加 | 大家按原比例一起掏钱，比例不变；谁不掏，谁的比例下降 | 法律规定原股东有优先认缴权 |

**稀释举例**：公司投资前估值 300 万元，新股东投 100 万元，投资后估值 400 万元，新股东占 25%。原持股 35% 的股东降到 26.25%，但所持股份的价值 35% × 300 万 = 26.25% × 400 万 = 105 万元，一分没少。价格公道的稀释不吃亏，要防的是低价增资：协议写明增资价格不低于最近一次估值或净资产。

**技术方的原则**：增资时技术方的股份可以被稀释，但须技术方同意的事项不随股份稀释而减少。具体怎么写，到时再商量。

### 5. 技术归谁

| 项 | 归谁 |
|---|---|
| 软件、代码与后续改进 | 技术方的公司，许可给数字化合作公司使用；AI 调用费用由技术方承担 |
| 各工厂的配置与数据 | 该工厂 |
| 驻厂工程师课程 | 技术方 |

### 6. 钱怎么分

**每一笔收入**

| 收入 | 数字化合作公司 | 技术方 | 介绍人 |
|---|---|---|---|
| 模块费、降本增效项目费 | 先抽 10%；介绍人是其他销售时，再得整单的 6.5%（合计整单 16.5%） | 合伙人介绍时：剩下的 70%（即整单 63%）；其他销售介绍时：整单 70% | 合伙人：剩下的 30%（即整单 27%）；其他销售：剩下的 15%（即整单 13.5%） |
| 实施人天费、变更单 | 不抽；介绍人是其他销售时得 15% | 70% | 合伙人 30%；其他销售 15% |
| 年维护费 | 不抽 | 100% | 不分 |
| 驻厂工程师线下实践课 | 先扣材料、学员意外险等直接成本，再抽 10% | 剩下的 50% | 示范工厂得剩下的 50% |
| 驻厂工程师线上课 | 不经过数字化合作公司 | 100%，由技术方的公司直接收 | — |

「其他销售」指不持股、签渠道协议的介绍人。不论介绍人是谁，每一单都先抽 10% 到数字化合作公司。介绍人是其他销售时，技术方拿整单的 70%，介绍人拿扣掉 10% 后的 15%（即整单 13.5%），剩下的整单 16.5% 归数字化合作公司。例：一单 10 万元，技术方 7 万元、介绍人 1.35 万元、数字化合作公司 1.65 万元。公司做大以后，这 10% 就是全体股东共同的长期收入。

**算例：外部工厂首期 17.5 万元**（模块费 13 万元，实施 30 天 4.5 万元）

| | 数字化合作公司 | 技术方 | 介绍人 |
|---|---|---|---|
| 模块费 13 万 | 1.3 万 | 8.19 万 | 3.51 万 |
| 实施费 4.5 万 | — | 3.15 万 | 1.35 万 |
| **合计** | **1.3 万** | **11.34 万** | **4.86 万** |

此后每年的年维护费 1.3～2 万元全部付技术方，用于持续的维护人力与服务器。

**怎么付**

| 项 | 做法 |
|---|---|
| 客户分期付款 | 签约付 30%、上线付 40%、验收付 30% |
| 每笔到账怎么分 | 每笔到账都按上表比例分，不等全款到齐；介绍费与技术服务费同时付 |
| 介绍费怎么分 | 合伙人那 30% 怎么分由合伙人之间商量，付给合伙人书面指定的收款人 |

**出了问题谁负责**

| 情况 | 谁负责 |
|---|---|
| 系统质量问题（功能做不出来、出错） | 技术方负责修好；修不好要退款的，技术服务费按退款比例退回 |
| 介绍人承诺了合同以外的内容，引起纠纷或退款 | 从该介绍人的介绍费里扣 |
| 其他原因的退款、赔偿 | 用数字化合作公司的风险准备金 |

### 7. 数字化合作公司的 10% 怎么用

按以下顺序：

| 顺序 | 用途 | 说明 |
|---|---|---|
| 1 | 公司运转 | 代理记账、报税、银行账户、年报，每年几千元 |
| 2 | 风险准备金 | 用于退款、赔偿、售后纠纷；数字化合作公司是签约方，出了问题先由它兜底；攒到 5 万元为止 |
| 3 | 共同获客 | 公司自己的宣传内容（AI 搜索推荐、视频号）、示范基地接待资料、行业展会 |
| 4 | 新项目所需硬件 | 在示范工厂试用新项目要买的传感器、平板等，归数字化合作公司所有 |
| 5 | 年度业绩奖 | 见下 |
| 6 | 年底分红 | 剩下的按股份分 |

**年度业绩奖**：分红只按股份，与每个人带来的业务量无关。为了多卖多得，每年从分红前利润里拿出一部分（起点 20～30%），按各人全年介绍成交的业务额发业绩奖。持股的、不持股的介绍人都能拿。

**谁能动这笔钱**：每年股东会定一次预算。预算内的开支由法定代表人执行；超出预算，或单笔超过大额标准的，须股东会同意。

### 8. 法定代表人、监事与账户

| 项 | 做法 |
|---|---|
| 法定代表人 | 由一位销售合伙人担任（初步设想为示范工厂负责人），同时是公司唯一的董事，公章由其保管 |
| 监事 | 由技术方本人担任：检查公司财务、监督董事；不参与日常经营 |
| 查账 | 技术方可以随时查账，银行到账有通知 |
| 大额付款 | 银行开两级 U 盾，超过一定金额的付款须技术方复核确认 |
| 记账 | 外包代理记账，每月报表发给全体股东 |

两个人一起管账，日常不用技术方操心，大钱也动不了，对双方都是保护。

### 9. 要签的文件（由律师起草）

| 什么时候 | 文件 | 谁签 | 主要内容 |
|---|---|---|---|
| 成立公司时 | 股东协议 | 全体股东 | 见下表 |
| 成立公司时 | 公司章程 | 全体股东，工商备案 | 表决、分红、须技术方同意的事项、转让限制；章程对外有效、股东协议只约束签字人，关键条款两份都写 |
| 成立公司时 | 技术许可与服务协议 | 技术方的公司与数字化合作公司 | 见下表 |
| 成立公司时 | 保密协议 | 所有人，含员工与学员 | — |
| 每位不持股的介绍人 | 渠道协议 | 数字化合作公司与介绍人 | 介绍费 15% 与计算基数、随每笔到账付、出了问题按责任表扣；不得承诺系统没有的功能；不得私下接单；介绍费个税（代扣，或对方注册个体户开票） |
| 每个新项目 | 一页立项附件 | 数字化合作公司与技术方的公司 | 立项登记、试用标准、市场价与试验厂价 |
| 办驻厂工程师线下课时 | 培训合作协议 | 数字化合作公司与示范工厂 | 分成办法、课程归属、学员去向、安全责任 |

**股东协议条款**（起点）

| 类别 | 写法 |
|---|---|
| 出资 | 现金出资；场地以租赁方式提供，不折成股份；注册资本定小，5 年内缴足 |
| 表决与分红 | 同股同权、同股同分红；写明按实缴还是认缴 |
| 股份分期到手 | 3 年到手、满 1 年起，对所有股东都适用，包括技术方的公司；到手条件：销售合伙人每年至少介绍成交 1 单，技术方持续提供交付与维护（见下方举例） |
| 退出 | 没到手的部分由其他股东按持股比例、以象征价买回；已到手部分按净资产或约定公式回购；违反竞业或保密的，低价回购 |
| 转让 | 设锁定期；随售与拖售（见下方举例） |
| 增资 | 增资价不低于最近估值或净资产；新股东须签本协议 |
| 决策 | 须技术方同意的事项（见第 3 项） |
| 管理 | 只设一名董事，由法定代表人担任；设一名监事，由技术方本人担任；公章与 U 盾分管，大额两人签 |
| 财务 | 外包记账，每月报表发全体股东 |
| 分红 | 每年至少分配可分配利润的一定比例；先弥补亏损、再提 10% 法定公积金 |
| 竞业 | 逐项列出、写窄，双方都受约束；写明技术方公司的其他业务不受限 |
| 客户归属 | 合作期间客户归数字化合作公司；退出后若干年内不得挖走 |
| 僵局 | 冷静期 → 第三方调解 → 一方报价、另一方选择买或卖 → 解散 |
| 争议 | 本地仲裁委：快、不公开 |

**股份分期到手举例**

股份在公司成立时就全部登记在本人名下，照样分红、投票；股东协议另外约定，按干满的时间逐步「到手」。成立时各股东预先签好转让文件，人走时直接办变更。假设某合伙人持股 20%：

- 干了 8 个月就退出：不满 1 年，20% 全部由其他股东按象征价买回
- 干满 1 年退出：三分之一（约 6.67%）已到手、留下，其余约 13.33% 买回
- 其余三分之二（约 13.33%）在之后 24 个月里平均到手：每满一个月，到手其中的 1/24（约 0.56%）
- 满 3 年，20% 全部到手
- 某一年没有介绍成交一单：这一年该到手的部分暂缓，下一年达标时一并到手

这一条防的是有人早早不干了，还一直拿着股份分红、投票。

**随售与拖售举例**

- **随售（一起卖）**：合伙人甲持股 40%，外人出 80 万元买下他的全部股份（每 1% 合 2 万元）。其他股东可以要求外人按同样的价格和条件，把自己的股份也买下，不会被留在一家换了大股东的公司里。
- **拖售（强制一起卖）**：有人要买下整个公司。持股合计超过约定门槛的股东同意卖时，其余股东须按同样价格一起卖，避免少数股东卡住整体出售。为防被迫贱卖，门槛设高（如 70%），并设底价（如不低于最近一次估值或净资产）。

**技术许可与服务协议条款**（起点）

| 条款 | 写法 |
|---|---|
| 许可范围 | 非独占、有期限，限地区与行业 |
| 知识产权 | 通用代码与改进归技术方的公司；各工厂配置与数据归该工厂 |
| 源代码 | 不交源代码；可交第三方托管，技术方公司停业或无法服务时，数字化合作公司可取得源代码继续维护（这一条是给数字化合作公司的保障） |
| 赔偿上限 | 以合同金额为限 |
| 控制权变化 | 数字化合作公司换控股股东时，许可重新谈 |
| 终止 | 提前通知；终止后协助交接若干个月 |
| 双向排他 | 数字化合作公司的数字化项目优先或独家交给技术方的公司；技术方的公司不在本地区另找驻厂工程师线下培训的合作方 |

## 三、合作项目

### 1. ERP

| 项 | 做法 |
|---|---|
| 模块费 | 13 万元，含已做好的 9 个模块（见下表） |
| 实施费 | 按人天收，每天 1500 元；一家工厂约 30～60 天，合计 4.5～9 万元 |
| 外部工厂首期 | 模块费加实施费，合计 17.5～22 万元 |
| 合伙人自家工厂（合伙人价） | 自己介绍自己：照常先抽 10%，介绍人那份（整单 27%）返给自己作为折扣，即市场价的 73%；模块费 13 万元实付约 9.5 万元；免实施费 |
| 合伙人退出后 | 按其他销售介绍的价格补差价：介绍费从 30% 降为 15%，补回整单的 13.5%；模块费 13 万元补约 1.76 万元 |
| 年维护费 | 模块费的 10～15%，每年 1.3～2 万元；合伙人自家工厂同样按 13 万元计，不打折 |
| 年维护包含什么 | 合同写清：服务器与备份、远程支持多少小时、上门几次、版本升级 |
| 停付年维护 | 数据始终归工厂。停付后系统转为只读 3 个月，期间可免费导出全部数据；也可付迁移费，把系统搬到工厂自己的服务器上 |
| 合同范围 | 合同写清交付哪些模块、包含多少人天；超出范围的另开变更单，按人天收费，介绍人同样分成 |
| 谁定价 | 市场价由合伙人定；包括底价在内的所有价格双方共同商量 |
| 起步收什么 | 起步阶段只收 ERP 的钱，签约即付款；其他项目按第 2 项的办法 |

**9 个模块**

| 模块 | 万元 |
|---|---|
| 财务 | 1 |
| 进销存 | 2 |
| 生产制造 | 3 |
| 车间管理 | 2 |
| 销售漏斗 | 1 |
| 手机端 | 0.5 |
| 质检与控制图 | 2 |
| 计件工资 | 0.5 |
| 补货策略 | 1 |
| **合计** | **13** |

ERP 本身不按用户数收费。排产优化、企业信息面板、车间 3D、岗位页面、AI 工作流等还没做好的模块，不在 13 万元里，做好后按第 2 项的办法另行报价。

服务器由技术方统一提供，工厂要自己准备的硬件见附录。

### 2. 降本增效项目

ERP 以外，帮工厂省钱、省人、提高效率的项目。

**怎么合作**

| 项 | 做法 |
|---|---|
| 流程 | 双方一起探讨可行性 → 技术方开发 → 在试验厂试用到运行稳定 → 双方共同决定是否推向市场 → 按合伙人定的市场价销售 |
| 谁判断可行 | 技术方判断技术上做不做得出来；合伙人结合成本判断市场上卖不卖得动 |
| 运行稳定的标准 | 试验厂连续用 4～8 周、员工每天在用、没有丢数据一类的问题；双方签一页纸确认 |
| 研发成本 | 由技术方承担，不向合伙人收取 |

**三个价**（例：项目市场价 10 万元）

| 谁买 | 价格 | 例 | 怎么付 |
|---|---|---|---|
| 外部工厂 | 市场价 | 10 万元 | 按第二节第 6 项分期付、分配 |
| 合伙人自家工厂 | 合伙人价：自己介绍自己，介绍费返给自己，即市场价的 73%，与 ERP 同一算法 | 7.3 万元 | 同上 |
| 试验厂 | 半价 | 5 万元 | 先用后付：项目推向市场后，用这位合伙人卖这个项目拿到的介绍费来抵，抵完后照常拿介绍费；金额按推向市场那天的市场价锁定，不设期限；项目最终没有推向市场的，不用付 |

试验厂是某位合伙人的工厂，每个项目一家。

**合伙人中途退出**

| 情况 | 怎么办 |
|---|---|
| 试验厂的合伙人退出，还想继续用 | 半价优惠取消，按外部工厂对待：补到市场价，已经用介绍费抵掉的部分扣除 |
| 以合伙人价买的工厂，合伙人退出 | 按其他销售介绍的价格补差价：介绍费从 30% 降为 15%，补回整单的 13.5%（市场价 10 万元的项目补 1.35 万元），之后照常使用 |

**试验厂退出时补多少（例：项目市场价 10 万元）**

| 退出时已用介绍费付了 | 想继续用，还要补 | 合计 |
|---|---|---|
| 0 | 10 万元 | 10 万元 |
| 2 万元 | 8 万元 | 10 万元 |
| 5 万元（半价已付清） | 5 万元 | 10 万元 |

**可以做哪些**（每一项都按上面的办法推进）

| 类别 | 具体内容 |
|---|---|
| 车间可视化 | 车间数字孪生、企业信息面板、车间看板 |
| 规范化文档 | 用 AI 起草 ISO9001、IATF16949 体系文件、作业指导书、检验规范、5S 与目视化标识设计 |
| AI 助手与知识库 | 维修经验库、工艺参数库、报价助手、内部问答 |
| AI 工作流 | 财务、销售等岗位的固定工作交给 AI 打草稿（见下） |
| 宣传与获客 | 工厂宣传片、产品与工艺短视频、官网、公众号、视频号、抖音、1688 与阿里国际站商品页；在 AI 搜索中被推荐另见第 3 项 |
| IT 运维 | 网络、备份、监控、账号权限，按年运维 |

**AI 能帮上哪些忙**

分工的原则：规则写得清的交给 ERP，要看材料下判断的交给 AI，拍板的交给人。AI 打八成草稿，人做两成判断。

办公室：

| 岗位 | 以前 | 用 AI 以后 |
|---|---|---|
| 销售报价 | 客户微信发来图纸或截图，人工看规格、查价格、做报价单，半小时以上 | AI 读图，提出线径、外径、圈数、材质，生成报价草稿，人核一遍就发 |
| 销售跟进 | 靠记性 | 微信语音转成订单要点，到期自动提醒跟进 |
| 采购 | 几家供应商的报价单手工汇总比较 | 把报价单丢进去，自动出比价表 |
| 财务 | 发票、流水手工录入；月底跟客户对账逐行核对 | 识别后自动录入；两份对账单自动标出差异；自动起草催款函 |
| 人事行政 | 考勤异常逐条翻；写招聘启事 | 自动汇总异常；生成招聘启事和面试题 |
| 管理 | 开会记笔记，事后整理 | 录音后自动出纪要和待办；周报从系统数据自动生成 |
| 外贸 | 邮件翻译、写回复 | 自动翻译并起草回复 |
| 老板 | 想知道数字要打电话问人 | 直接问「这个月哪个客户回款最慢」 |

车间：

| 场景 | 用 AI 以后 |
|---|---|
| 图纸转工艺 | 客户图纸自动生成工艺卡和 BOM 草稿 |
| 报工 | 工人对手机说一句「工单 123 做了 500 件」就报完 |
| 质检 | SPC 异常自动报警并列出可能原因；以后可以上视觉检测，用相机查尺寸和外观缺陷 |
| 排产 | 插单时先模拟，看会影响哪些交期 |
| 安全 | 摄像头识别没戴安全帽、闯入危险区域 |
| 设备 | 加装电流或计数传感器，提前发现异常 |

**财务 AI 工作流**

| 工作流 | 流程 | AI 下的判断 |
|---|---|---|
| 经营月报 | ERP 出数 → 与上月、预算比 → 挑变化最大的几项 → 到凭证里找原因 → 写成老板看得懂的月报 → 财务审核 | 哪些变化值得说、原因是什么（如制造费用涨 18%，是因为 3 张维修单） |
| 应收催收 | 每天看账龄、回款历史、聊天记录 → 欠款客户分类 → 按类型起草催款话术 → 建议是否停供 → 人发出 | 客户是忘了、资金紧张，还是对货有意见 |
| 客户对账 | 客户发来的 Excel、PDF、照片 → AI 读出后与 ERP 逐行核 → 解释差在哪 → 起草回复 | 读懂各种格式；差额是没开票、在途还是价格不同 |
| 报销审核 | 读发票、报销单、出差审批 → 对照文字报销制度 → 标出异常并说明 → 人审批 | 拿一段文字规定判断一张票是否合规 |
| 毛利漏在哪 | 实际毛利与标准毛利对不上 → 查哪些工单、哪些材料涨价 → 写分析 | 找出主因 |
| 资金预测 | 结合各客户平均晚付天数、应付到期、工资 → 未来 13 周资金预测与说明 | 估每个客户实际哪天付款 |
| 财税政策解读 | 读新的财税公告 → 说明对本公司的影响并附出处 → 人核实 | 哪些条款与本公司有关 |

**销售 AI 获客工作流**

| 步骤 | AI 做什么 | 人做什么 |
|---|---|---|
| 1 画理想客户 | 从 ERP 现有客户里找毛利最高、回款最好的那类（行业、地区、订单规模） | 确认 |
| 2 找线索 | 从企业公开信息、1688、展会名录、招标公告、招聘信息（在招人说明在扩产）里找符合画像的企业，并写理由 | — |
| 3 研究打分 | 读对方官网的产品，推测会用什么弹簧，按匹配度打分 | 挑要跟的 |
| 4 首次联系 | 结合对方产品起草针对性的第一条消息 | 审核后一条条发，不群发 |
| 5 内容吸引 | 把工厂素材写成视频号、抖音脚本与公众号文章 | 拍摄 |
| 6 回复询价 | 微信、1688、官网来的询价，AI 读图提规格、追问缺的参数、按 ERP 报价规则给区间，转给销售 | 定价、谈判 |
| 7 跟进 | 沟通记进 CRM，提醒下一步，按客户上一条消息起草跟进；发现下单变少时提醒 | 维护关系 |
| 8 复盘 | 每周分析赢单、丢单的原因 | 改话术与画像 |

合规：只用企业公开信息，不买个人手机号数据，不群发骚扰。最好的演示是数字化合作公司自己先用这套流程找客户。

### 3. 在 AI 搜索中被推荐（GEO）

这是帮工厂对外获客的业务，不在工厂内部，所以与降本增效项目分开。新服务的推进办法同第 2 项。

目标是让豆包、元宝、DeepSeek 等 AI 在回答「哪家弹簧厂做得好」一类问题时，提到并推荐这家工厂。

| 步骤 | 做什么 | 交付物 |
|---|---|---|
| 1 诊断 | 整理 30～50 个买家真会问的问题，逐个去问 AI，记下有没有提到、排第几、引用了哪个来源、正面还是负面 | 基线报告 |
| 2 定内容 | 根据 AI 爱引用的来源，规划要写什么：参数、对比、案例、常见问题 | 内容清单 |
| 3 做内容 | 写成结构清楚、有具体数据、可以被直接引用的内容：官网常见问题页、百科词条、头条文章、带字幕和文案的抖音视频 | 内容本身 |
| 4 分发 | 发到 AI 常引用的平台；一次拍摄多处分发（视频号、抖音、公众号、头条、官网） | 发布记录 |
| 5 监测 | 每月复测同一批问题，看提及率、排名、正负面怎么变 | 月报 |

先给数字化合作公司自己做，做出效果再作为服务卖给其他工厂。各平台的引用来源以实测为准。

### 4. 示范基地

获客主要靠请其他工厂来示范工厂参观，看到实际效果再谈。

| 环节 | 内容 | 谁主导 | 怎么收费 |
|---|---|---|---|
| 1 参观示范基地 | 规范化车间、看板、ERP、AI 现场演示 | 示范工厂 | 免费，用来获客 |
| 2 诊断 | 精益规范化与数字化诊断报告 | 示范工厂与技术方 | 小额，可抵后续改造费 |
| 3 改造 | ERP、降本增效项目 | 技术方交付 | 一次性加年维护 |
| 4 运营 | 宣传获客、视频号与抖音、官网 | 技术方或驻厂工程师学员 | 按降本增效项目的办法定价 |
| 5 培训 | 驻厂工程师培训班；工人培训（如果一起合作） | 驻厂工程师班由技术方主导；工人培训由示范工厂主导 | 学费，可能有政府补贴 |

示范基地的展示内容：展厅大屏、车间数字孪生、企业信息面板、参观动线上的讲解视频。

### 5. 驻厂工程师（FDE）培训班

驻厂工程师指懂工厂业务、也能动手配置系统的实施人员。

| 项 | 做法 |
|---|---|
| 目的 | 除收学费外，也为其他工厂和技术方培养驻厂工程师，解决交付只靠一个人的问题 |
| 线上课 | 由技术方的公司开、收款，收入归技术方，开课不受限制 |
| 线下实践课 | 由数字化合作公司收款，只在示范工厂上；未经示范工厂同意，不与别的工厂合办；分配见第二节第 6 项 |
| 怎么算线下 | 含工厂实操的整门课都算线下 |
| 学员来源 | 工厂的文员、IT 或年轻管理者（学成回厂当数字化负责人，工厂成为长期客户）；职校毕业生（可成为实施工程师） |
| 学员去向 | 自由；技术方的公司可以招聘学员；其他工厂招走学员时收推荐费，归数字化合作公司 |
| 学员安全 | 线下学员都买意外险、签安全须知 |

### 6. 工人培训（是否一起合作还没定）

**技术方能为工人培训做的配套**

| 类别 | 具体内容 |
|---|---|
| SOP 视频化 | 每道工序拍成 2～3 分钟视频，工位贴二维码，扫码就能看；可以直接问「这台机器报 E07 怎么办」，答案来自老师傅的维修记录 |
| 课件与题库 | 培训课件、考核题库 |
| 线上学习 | 线上学习平台与证书管理 |
| AI 陪练 | AI 陪练问答 |
| 调机仿真软件 | 见下 |

**调机仿真软件**

先做网页版 3D 参数仿真：学员在虚拟面板上输入参数，3D 画面看弹簧成型，量自由长度、外径、节距判断合不合格，并预设常见故障练排查。重点练调机（送线长度、芯轴与顶杆位置、节距、切断时机），因为调机费钢丝、占机器、靠老师傅带。网页打开就能用，不绑某个品牌的机器。

开工前要准备：卷簧机的品牌与控制器型号、一段老师傅从头到尾调机的录像、钢丝回弹的实测数据（用来修正仿真结果）。

**如果一起合作**

| 项 | 做法 |
|---|---|
| 公司 | 另办工人培训合作公司，与数字化合作公司分开。两块业务主要出力的人不同；培训可能要办学资质、学员实操有安全责任，分开能隔离风险 |
| 合作路线 | 0 自己办培训 → 1 技术方做培训配套，按第 2 项降本增效项目的办法、试验厂半价 → 2 合办工人培训合作公司，由培训方主导 |
| 技术方的股份 | 以全部数字化基建换工人培训合作公司 15% 的股份 |
| 课程教材 | 工人培训课程教材归工人培训合作公司；驻厂工程师课程归技术方 |

**15% 怎么落实**（起点）

| 要写清的 | 写法 |
|---|---|
| 「全部数字化基建」包括什么 | 列清单：仿真软件、线上学习平台、SOP 视频、题库、培训档案，加头若干年维护；清单以外的新需求另收费 |
| 股份怎么出资 | 按 15% 的比例出少量现金，基建交付写进服务协议；不把基建作价入股 |
| 股份什么时候到手 | 与交付挂钩，如学习平台上线 5%、仿真软件上线 5%、第二年运行正常 5% |
| 东西归谁 | 通用软件（仿真、学习平台）归技术方的公司，免费长期授权工人培训合作公司使用；该厂专属内容（老师傅出镜的 SOP 视频、工人课程教材）归工人培训合作公司 |

走到第 2 级时，第 1 级已做的配套并入基建清单，未付清的部分不再付。

**培训资质**：发国家认可的职业技能等级证书、拿政府培训补贴，一般要有人社部门的资质；不发证的企业内训，营业范围含培训即可开展。工人培训的收入很大程度取决于补贴，须先向当地人社局问清楚。

**服务器由技术方统一提供**，费用含在服务费里：一台服务器可以服务多家工厂，各家不用自己买，整体更划算。工厂如果为了数据安全想把系统放在自己厂里，也可以自己买（表中「自建时」各行）。

价格全为估算；工厂已有的设备先盘点，能用就不买。车间终端按约 7 个作业区估。工厂要自己买的：必需项约 0.5～2 万元；建议项再加 3～6 万元；可选项按需另算。自建服务器另加约 0.8～2 万元。
