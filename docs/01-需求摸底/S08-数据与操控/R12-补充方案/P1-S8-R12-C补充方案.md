## 一、概述

**问题**：
1. 第 9 幕打开供应商评分卡列表，12 家全是 Very Poor（7.5～23.9 分），整张列表都是红的。
2. 第 9 幕讲「价格与履约表现一并参考」，可是接下来的「采纳」只生成一张物料需求，上面没有供应商；整幕也没有下采购单。客户看不到按评分选了哪家。

**用户裁决**：

| 时间 | 裁决 |
|---|---|
| 2026-10-27（C 开工前） | 改判，允许调整评分口径：无单月份不计分 |
| 2026-10-28（R12 开工，见 §2 调研后） | 选「拒收率分化」：无单月份不计分；准时一项改用口径正确的原生变量；各供应商拒收率不同、合格一项扣分收紧，让等级真正拉开 |
| 2026-10-28（v1.1） | 演示要让客户看到各家评分不同，并演示按评分选供应商。原生 `on_time_shipment_num` 口径错误登记延迟（`SH-P1S8035`），本次不修；方案补「按评分选供应商、下采购单」一步 |

**完成标准**：

- 无收货的月份不进加权；交货与合格两项各占 50 分，只用原生变量计算。
- 生成器按供应商取不同拒收率；没配的供应商退回全局 `rejected_ratio`。
- 第 9 幕采纳物料需求后，按评分和当月价选定供应商，生成并提交采购订单。选中的供应商不是当月最便宜的那家，讲词点明「最便宜的那家评分低，选了评分高、价格接近的那家」。
- 整场重跑后第 9 幕快照：12 家里没有 Very Poor，至少两种等级；`WIRE-65MN-3.0` 当月最便宜的那家不是四家里的最高等级。
- 同一次整场重跑里核掉 FD-037：web 日志 `FileNotFoundError` 为 0。

## 三、接口契约

### 3.1 评分口径（`frappe_debug/scenario/support.py`）

```python
SCORECARD_CRITERIA: Final[tuple[tuple[str, str], ...]] = (
    ("S8 交货及时", "max(0, 100 - 10 * {tot_days_late} / ({total_received_items} + 1))"),
    ("S8 来料合格", "max(0, 100 - 1000 * {total_rejected_items} / ({total_received_items} + 1))"),
)   # 各 50 分权重，max_score 100
SCORECARD_WEIGHTING: Final[str] = (
    "{total_score} * max(0, min(1, (12 - {period_number}) / 12))"
    " * (1 if {total_received_items} > 0 else 0)"
)

def make_supplier_scorecards(sc) -> list[str]:
    """签名不变。标准建法同现行（creation 改到 S、按月、scenario_standings）。
    评分标准按名称 upsert：不存在则建；已存在且 formula／max_score 不同则改成上面的值。
    已有记分卡：weighting_function 或 criteria 与上面不同 → frappe.throw("评分口径已变，须从清洁基库重新生成场景")，
    不改任何记录（已提交的期按旧公式算过，混在一起就不对了）；相同 → 只刷新 standings（现行行为）。"""
```

口径含义：

- **交货及时**：按收货数量加权的平均迟到天数，每天扣 10 分（`tot_days_late` 是原生的「迟到天数 × 数量」，含到期末仍未收的数量）。
- **来料合格**：拒收率每 1% 扣 10 分，拒收率达 10% 时为 0。
- **不计分月份**：本期收货数量为 0（以收货单 `posting_date` 落在本期为准）。期仍然建、`total_score` 仍为数值（AC-019「无空分」照旧），只是权重为 0。
- 旧评分标准名「S8 准时交货」「S8 合格率」不再使用，新名称避免和已有库里的旧公式混淆。

### 3.3 按评分选供应商（`frappe_debug/scenario/support.py`，纯函数，演示与 `verify` 共用）

```python
STANDING_RANK: Final[dict[str, int]] = {"Excellent": 3, "Average": 2, "Poor": 1, "Very Poor": 0}

def choose_supplier_by_standing(rows: list[dict]) -> dict:
    """纯函数。rows：同一物料各家 {supplier, rate, supplier_score, status}（rate 为当日采购价）。
    cheapest = min(rows, key=(rate, supplier))
    best_rank = max(STANDING_RANK[r.status])
    chosen = min([r for r in rows if rank == best_rank], key=(rate, supplier))
    返回 {"cheapest": cheapest, "chosen": chosen, "candidates": rows 按 rate 升序,
          "tells_story": chosen.supplier != cheapest.supplier}
    rows 为空、某行 rate 为空或 status 不在 STANDING_RANK 里 → frappe.throw，并写明是哪家。"""

def act9_supplier_rows(sc, day: date) -> list[dict]:
    """取 act_targets.act9_eoq_item 那种线材 suppliers 的各家：当日价（Standard Buying、该供应商、
    valid_from ≤ day 的最新一行，同 builders/buying.py 取价）、Supplier Scorecard 的 supplier_score 与 status。
    某家缺价或缺记分卡 → frappe.throw，写明是哪家。"""
```
