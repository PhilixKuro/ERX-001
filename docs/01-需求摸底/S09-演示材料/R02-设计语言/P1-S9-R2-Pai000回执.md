## 复核建议

1. **最没被验证的改动**：没有在真机上双击打开过，只用无头 Chrome 测了 `file://`。U 盘、别的电脑、Edge 浏览器都没试。另外 `color-mix()` 需要 Chrome 111 及以上，旧浏览器上徽标会没有底色。
2. **依赖推断的判断**：扩规模后，订单数量、喷丸检验包装的工时、信用额度、制造费用系数 3.5 都是为了演示好看而调出来的，不是场景实测数，也不是行业数据。毛利率在 34%～51%，比月度经营数据里的 33.5% 高。两者是分开写的，客户如果对比单品毛利和月度毛利，会发现对不上。
3. **拿不准处**：「能不能接」用的是简化排程（逐道工序挑最早空出的设备，不考虑插单重排）。界面上讲「排到哪天」够用，但它不等于真正的 CTP。
