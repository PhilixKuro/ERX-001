## 复核建议

1. **最没被验证的改动**：拖动旋转、触屏、真机双击、Edge 都没试；无头 Chrome 用软件渲染能跑，但旧电脑或投影机上的帧率没量过。3D 是用户选的方案，Claude 当初列的缺点就是「旧电脑或投影机上可能卡」，演示前最好在要用的那台电脑上开一次。
2. **依赖推断的判断**：回放里往后时段只分运行、空闲（加上喷丸机-1 停到 15:00、卷簧机-4 待料到首道开工），「超负荷」「异常」只在此刻出现；料箱停在第一道没完工的工序，同一张单的后道已开做时，设备标签和料箱位置会不在一处（如 00306）。
3. **拿不准处**：此刻包装线-1 的标签显示「上道检验未放行」，而驾驶舱抽屉「正在做」显示 00301，两页在这一处说法不同。
