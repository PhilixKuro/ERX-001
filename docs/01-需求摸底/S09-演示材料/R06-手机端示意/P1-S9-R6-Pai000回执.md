## 复核建议

1. **最没被验证的改动**：真手机、触屏、Edge、真机双击都没试；无头 Chrome 只验了 `file://` 可开、控制台 0 条、400px 不横向滚动。手机外框在 1366×768 这类矮屏上的高度只算过（`min(844px, 100vh − 48px)`），没截图。
2. **依赖推断的判断**：计件单价是 Claude 按「满负荷一天约 190～240 元」定的，不是场景里的数；上午已报良品按 08:00 到 10:30 标准工时连续生产算，没有扣停机或换型。两者与成本模型里的人工不是同一套口径（LG-002）。
3. **拿不准处**：报工只在手机页里累加，报完切回驾驶舱或孪生，数字不会变（LG-003），演示时要口头带过。
