## 当前编排

**`shapeApply` Workflow**（非自由编排）。文件：[../../流程体系/workflows/shapeApply/0-shapeApply-workflow.md](../../流程体系/workflows/shapeApply/0-shapeApply-workflow.md)

**原子 Stage**（不是议题）。三个步骤：**A** 讨论（shape）→ **B** 按讨论改文件（build）→ **C** 落实审核（audit）。B 与 C 都是可选的——A 收敛后若无待改文件即收口；B 跑完改动面小到无需独立审核时由用户裁决可直接收口。

**为何走 shapeApply 而非 plannedDev**（路线文档 §四 S3 的判据）：三项产出都是"讨论收敛时已知每处改哪个文件的哪一节"（术语标准表、参数复核结论、问点清单），**无需先冻成开发方案**。本 Stage **全部无编码**。
