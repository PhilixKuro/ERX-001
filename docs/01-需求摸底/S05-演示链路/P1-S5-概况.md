# P1-S5 演示链路 — Stage 概况

> Stage 级概况：当前 Workflow 是哪条、进行到哪个步骤/轮次、本 Stage 延迟需求登记册。

## 当前编排

**`plannedDev` Workflow**（非自由编排）。文件：[../../流程体系/workflows/plannedDev/0-plannedDev-workflow.md](../../流程体系/workflows/plannedDev/0-plannedDev-workflow.md)

**原子 Stage**（不是议题）。六个主链步骤：**A** 需求讨论（shape）→ **B** 需求文档（build）→ **C** 开发方案（build）→ **D** 代码（build）→ **E** 确认（confirm）→ **F** 审核（audit）。两个可选步骤：**SA** 探针（spike，A 或 D 唤起）／**SB** 修复（build，E 或 F 唤起）。

**为何走 plannedDev**（路线文档 §四 S5 的判据）：CRM 衔接点配置、Raven 的 `Raven AI Function` 记录自建、HRMS 的 `Company.on_update` 交互都需先冻成方案；且 **IM-005 侵入度是六个候选里最高的**（`doc_events` 挂 28 个具体 DocType，`override_doctype_class` 覆盖 4 个），动架构。

**⚠ 一处偏离（路线文档 §四 S5 原文）**：同 S4，**D 步预设执行者 `CodeX` 改为 Claude**。

## 本 Stage 的范围（路线文档 §四 S5）

**权威依据**：[../0-P1文档/路线文档.md](../0-P1文档/路线文档.md) §四 S5。**本节不重复其内容**，只列执行时要随手可见的几项。

| 项 | 内容 |
|---|---|
| **目标** | 把四个 App 装进来，并确认异地演示环境真的通 |
| **纳入功能** | **CR-013** CRM 接入＋销售漏斗／**IM-005** HRMS 接入／**IM-006** Insights 接入／**EX-001** Raven（AI 演示）／**CR-015** 演示终端连通性 |
| **前置依赖** | **无**（S4 已收口，与本 Stage 无硬依赖；但本 Stage 的 HRMS 会触碰 S4 的成果，见 RW-01） |
| **产出后效** | **⚠ 必须在 S6 之前完成**（图谱 §7.4：每接入一个 App，S6 的 CR-002 与 CR-010 各增一份工作量）；CR-013 → S7 的 CR-012（硬次序④）；CR-015 → S7 的 CR-008／CR-009；EX-001 三问的结论 → S7 的 CR-012 数据怎么编；IM-005 → S8G 的 IM-016 |
| **工作量** | **6.5–11 人日**（Raven 取常规值时 6.5–9；C 步按 DEC-022 收窄、回写路线文档 v1.6。A 步 DEC-019 为 6.5–12，原 5.5–9.5） |

**完成标志**（四条，路线文档 v1.6 §三 S5 行，B 步按 A 步结论改写、C 步按 DEC-022 改第 4 条；逐条可验表述见 [B 需求文档](R02-需求文档/P1-S5-R2-B需求文档.md) §八 AC-001～AC-004）：

1. `Lead → Deal → Quotation → Sales Order` 链路实点通过，客户由 CRM 自动建出，该 Deal 出现在漏斗看板；
2. 四个 App 均装成，`frappe_china` 经调序回到四者之后，三个 whitelisted 覆盖解析到 `frappe_china`、一条撞源词测试译名由 `frappe_china` 胜出、建账自检直接调用全过；
3. Raven 只读 bot（`Get List`／`Get Document`＋报表通道）已建并经 LiteLLM 连通，**用户那三问各实测 3 次并记录答得出与否**；
4. **局域网环境下**，异地终端能打开页面、实收到一次本机推送的事件，且实时通道不通时同一检查报失败；**组网（外网）一段做到理论就绪**——使用说明、连通检查工具与外网实测前的准备清单齐备，外网实测移后（C 步 DEC-022，延迟需求 `SH-P1S5005`）。

**本议题执行所需的清单与边界**：路线文档 §四 S5 十条，原文不重复。最要紧的三条：HRMS 必须用 `version-16` 分支（第 1 条）；**不用 `override_doctype_class`**（第 3 条，ADR-0004）；**Raven 三问的实测结论直接决定 S7 的 CR-012 数据怎么编**（第 6 条）。
