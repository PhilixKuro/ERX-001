## 一、弹簧产品分类与典型规格

### 1.1 国标划定的弹簧大类

`GB/T 1805-2021《弹簧 术语》`的适用范围界定了弹簧类型边界：**螺旋弹簧、涡卷弹簧、碟形弹簧、板弹簧、非金属弹簧、气弹簧、扭杆弹簧、稳定杆及其他弹性元件**；材料术语与弹簧设备术语不在该标准内。

- （A）<https://std.samr.gov.cn/gb/search/gbDetailed?id=CE1E6A1DD46F58F6E05397BE0A0A68DF>
- 标准身份（A）：GB/T 1805-2021，修改采用 ISO 26909:2009（MOD），2021-10-11 发布、2022-05-01 实施，代替 GB/T 1805-2001。归口 SAC/TC 235 全国弹簧标准化技术委员会，CCS J26，ICS 21.160，61～64 页。
- ⚠ **全文未公开**：openstd 因其采用 ISO 标准而不提供全文阅读，只能付费获取。（A）<https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=496679CB86D63AED6F2EBF27908543AE>

### 1.2 圆柱螺旋弹簧的型式代号

### 1.3 压缩弹簧（俗称压簧）

**标准名称**：圆柱螺旋压缩弹簧。**常见俗称**：压簧、压缩簧。
**技术条件**：GB/T 1239.2-2009《冷卷圆柱螺旋弹簧技术条件 第2部分：压缩弹簧》（A）<https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C2B0D45F3EE2551DE252FE96F7DA9A75>

## 三、弹簧厂生产流程术语

⚠ **整节的来源级别最低（D 级）**：中小型弹簧厂的车间叫法**没有国家标准规定**，本节内容全部来自厂商公开资料与工艺文章，属行业惯用而非标准用语。

### 3.1 冷卷压缩弹簧的完整工艺路线

凡一商城给出的工序序列（D，措辞最接近车间工艺卡）：

> **球化退火 → 卷簧 → 去应力回火 → 端面磨削 → 校正 → 首次回火 → 喷丸 → 再次回火 → 立定或强压处理 → 倒角或去毛刺 → 检验 → 表面处理 → 成品检验**

<https://www.forrun.cn/article/2398.html>

一处值得注意的工艺逻辑：**喷丸前后各有一次回火**——喷丸引入的表面压应力需低温回火稳定，温度过高压应力反而衰减。

### 3.2 按车间/工序段的叫法

（D，综合厂商资料，数值均为厂商经验值而非标准）

| 工序段车间叫法 | 主要作业 | 厂商给出的参数区间 |
|---|---|---|
| 原材料 / 下料 | 来料成分、抗拉强度、表面、直径公差检验；圆盘锯下料 | 下料长 L ≈ π·D·N + 约 1.5 倍线径 |
| **卷簧**（卷簧车间） | 冷卷（CNC 卷簧机）或热卷 | 热卷加热 850–950℃，绕制不低于 800℃；芯轴比设计中径小 2–5% 补偿回弹 |
| **热处理**（热处理车间） | 冷卷件走去应力回火/去应力退火；热卷件走淬火+中温回火 | 淬火油 50–80℃，淬后 HRC 55–62；回火 350–450℃ 保温 30–60min，回火后 HRC 42–50 |
| **磨簧**（端面加工/磨口） | 砂轮磨平端圈、倒角 | 磨削量约 1/4–1/3 线径；端面 Ra ≤12.5μm；垂直度 ≤1.5% 自由长度 |

| **立定 / 强压** | 压至最大工作变形 3–5 次 | 自由长度会缩短 1–3% |
| **表面处理** | 电镀锌、磷化、发黑、达克罗、喷涂 | 以防腐为目的，一般排在检验之后、成品检验之前 |
| **检验 / 入库** | 自由长度、外径、垂直度、刚度、最大负荷、硬度、磁粉或渗透探伤、疲劳试验 | 自由长 ±1.5%、外径 ±1%、刚度 ±10% |

## 五、复核建议

### 5.1 最需要复核的（会直接影响演示数据正确性）

1. **第一节所有规格数值都是 B 级转录，不是国标正文。** 必须对 GB/T 2089-2009、GB/T 2088-2009 原文核验。已明确发现的问题：
   - 同一页面的搜索摘要与我直接解析 HTML 所得 Fn **数值冲突**（d=5/D=30：661 vs 962；d=8/D=50：1154 vs 2203；d=12/D=70：3441 vs 4922）。我采用解析值，但无法排除解析也有列错位。
   - 该站表格系 OCR 转录，检索提示存在错字（`11O`→`110`、`o.61`→`0.61`、`Z4`→`24`）。
   - 核验入口（免费在线预览）：GB/T 2089 <https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=43C3585AAFFC8E239A9E4924F2BEF0B3>
2. **拉簧表头「H-有效圈长度」的确切定义是我的推断**（依 H≈n×d 判断为不含钩环的簧身长度）。需查 GB/T 2088 原文。
3. **YA/YB 与 Y Ⅰ/Y Ⅱ/RY Ⅰ 两套型式代号的对应关系未查到**。若演示数据要用型号标记，这一处必须查清，否则标记会自相矛盾。
4. **凡一商城的标记示例把标准号误写为 `GB/T2009`**（应为 GB/T 2089）。引用标记格式时不要照抄该页。

### 5.2 拿不准的

5. **术语的定义文字全部不是 GB/T 1805 正文。** GB/T 1805-2021 因采用 ISO 标准而全文不公开；我下载到的 GB/T 1805-2001 PDF 是**扫描件无文字层**（Adobe-GB1 字体无嵌入 CMap，pdftotext 提取为空），另一个 antpedia 源需 referer 拒绝下载。第二节定义取自 mysteel 百科的术语对照表（其措辞与国标高度一致，但**属 B 级**）。且 2001 版仅约 129 条术语、2021 版约 229 条，**2021 版删除了独立「符号和单位」条款**，符号写法可能已变。若术语标准要正式落地，建议获取 GB/T 1805-2021 正版全文。
6. **旋向、螺旋角的标准英文与定义条款未查到**（旋向只确认存在于 GB/T 2089 标记规则中）。
7. **「并紧高度」不是查到的标准术语**；语义最近的标准词是**压并高度（Solid height）**。
8. **「卷簧、喷丸、回火、去应力退火」这几个最常用工艺词，未在 B 级术语表中找到条目**，只有 D 级厂商来源。GB/T 1805-2021 第 8 章「制造及工艺术语」应覆盖，未能核实。
9. **「刚度/弹性系数」**：标准词是**弹簧刚度**；「弹性系数」属俗称，未查到标准依据。
10. **12Cr18Ni9 ↔ SUS304 这个常见说法是错的**——它对应 **SUS302/AISI 302**；SUS304 对应 **06Cr19Ni10**。此结论来自 C 级材料数据库，牌号对照在碳、氮限值上存在差异，**若进采购规格须查 GB/T 24588-2019 附录 A 与表 1 原文**。

### 5.3 来源不够权威的（非国标）

11. **第三节生产流程整节为 D 级**（厂商营销页与工艺文章）。所有温度、硬度、公差、丸径、寿命提升倍数等数值都是厂商经验值，**不是标准值**，不可写入规格文件。中小弹簧厂车间叫法本身无国家标准。
12. **扭簧的厂商公式有互相矛盾之处**（刚度分母 3667·D·n vs 10.8·D·n），且一篇把扭簧簧体应力误标为剪应力 τ（实为弯曲应力）。这类公式已排除，不要引用。
13. 检索到一篇厂商文章**标注发布日期为 2026 年**，异常，已不采用其数值。
14. **SWP-A/SWP-B/SWP-V 是日标 JIS G 3522（琴钢丝），不是国标牌号**。项目若要用这组代号，须明确它是日标俗称。
15. **抗拉强度表取自 GB/T 4357-1989（旧版）**，其 B/C/D 级划分已被现行 2022 版的 SL/SM/SH/DM/DH 取代。**现行版按直径的抗拉强度表（表6）未查到**（需付费全文）。
16. **第四节 4.2 的 ERPNext 中文译法为 B 级**（ERPNext 中文网），我**未直接读取上游 erpnext 官方 zh.csv**（项目 `frappe-bench/apps` 下未找到 zh.csv）。实际 UI 字符串应以部署版本的翻译文件为准。

### 5.4 明确没查到的

17. **扭簧的典型规格具体数值**——未发现扭簧的「尺寸及参数」国标（压簧有 GB/T 2089、拉簧有 GB/T 2088，扭簧无对应），GB/T 1239.3-2009 正文的精度等级与公差表未取到。**任务要求的「2-3 个典型规格具体数值」这一项，扭簧缺失。**
