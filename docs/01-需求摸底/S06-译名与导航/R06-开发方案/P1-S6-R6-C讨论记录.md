**选项：**

| 选项 | 描述 | 优点 | 缺点 |

| 改译「收付款」（推荐） | 无 context 行改为「收付款」，进覆盖清单 | 与单据名「收付款凭证」对上；17 处出处方向中性、不误导 | 采购侧原本对的「付款」也变成「收付款」 |

**⑬ 坏行复数：实际约 5300 行，DEC-028 的范围被推翻**

**背景：** ② 的 2961 行用的是 E 报告的检测器，起草方案前对「检测器判为好」的行随机抽 40 条目视，大半仍坏（`'Jump to pinned message' → 'Jump 至 pinned 消息'`、`'Upload Photo' → '上传 Photo'`、`'This FY' → '此 FY'`）。补两种检测器重数：

| 检测器 | 判法 | 命中 |

| 占位 | 「中文：」开头或含「???」 | 696 |
| 中英混排 | 去掉占位符、HTML、白名单缩写与品牌名后仍剩英文词 | 898 |
| **合计** | 四类按上序归一类、不重复计 | **5325**／5852 |

检测器全判为好的只剩 527 行，其中多为本 app 自有源词（S4 建）。批量档实际上整体作废。
