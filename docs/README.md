## 命名导航

产物命名与目录结构的权威定义在 [流程体系/流程规范.md](流程体系/流程规范.md) §11。要点：

- **产物文件名**：`P{n}-S{m}-R{k}-{步骤字母}{产物名}.md`，全局唯一
- **Phase 目录**：`{NN}-{期名}/`（议题 Phase 为 `{NN}G-{议题名}/`），内含 `P{n}-概况.md`
- **Stage 目录**：`S{NN}-{阶段名}/`，内含 `P{n}-S{m}-概况.md`
- **Round 目录**：`R{NN}-{步骤名}/`，活链文件无 `-T{k}` 后缀
- **跨轮演进产物**（需求图谱 / 架构文档 + ADR / 路线文档）不带 PSR 段，按消费周期落 `0-项目文档/` 或 `0-P{n}文档/` 或 `0-P{n}-S{m}文档/`
- **失效试次归档**：各层的 `00-T{n}/`
